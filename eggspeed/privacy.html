EggSPEED

Privacy Policy

Last updated: August 7, 2026

EggSPEED talks to your bike's controller only over a wired USB cable. It has no internet access and transmits no data of any kind.

1. What EggSPEED Does

EggSPEED reads and displays the configuration and live telemetry of a Bafang BBS01, BBS02, or BBSHD mid-drive controller connected to your phone with a USB-OTG programming cable (serial UART, 1200 baud). All communication and processing happens locally, directly between your phone and the controller.

In this release, EggSPEED sends the controller only read commands, plus the same transient display commands (assist level, light) a factory Bafang display sends during normal riding. No command that writes configuration to the controller's flash memory exists anywhere in the app.

2. USB / Serial Access

EggSPEED requests USB host access (android.hardware.usb.host) so it can talk to the controller over the wired USB-OTG cable. No Bluetooth, Wi-Fi, or any other wireless radio is used or requested.

3. Data We Do Not Collect

EggSPEED does not collect, store, or transmit any data to us or anyone else. Specifically:

  • No personal information of any kind
  • No riding data, telemetry, or configuration sent anywhere
  • No location data
  • No usage statistics or analytics
  • No crash reports sent to our servers
  • No internet permission is requested at all - this can be verified directly in the app's manifest

4. Data Stored Locally on Your Device

EggSPEED stores the following data in your device's local app storage. This data never leaves your device:

  • App preferences - language (English/Polish) and speed unit (km/h or mph)
  • Odometer & trip data - your odometer offset and trip/energy-usage history, used to estimate average consumption and remaining range
  • Battery setup - the cell count and capacity you enter, used only to calculate range on the Cockpit screen
  • Calibration factors - optional current/voltage correction values you set on the Calibration screen
  • Saved profiles - configuration snapshots you choose to save, exported as .ini files only if you use the Export or Save current buttons

You can clear this data at any time by clearing the app's storage in your device settings, or by uninstalling the app. EggSPEED explicitly opts out of Android's automatic backup system, so none of this data is ever uploaded to Google's cloud backup.

5. Read-Only by Design

This version of EggSPEED (Milestone 1) contains no code path capable of writing configuration to the controller's flash memory. The only commands sent are reads and the same volatile display commands (assist level, light) a factory display sends every ride - so there is no risk of the app corrupting your controller's saved settings.

6. Network Access

EggSPEED does not request or use internet access or local network access of any kind. It functions entirely offline, over the USB cable only.

7. Third-Party Services

EggSPEED uses the open-source usb-serial-for-android library to communicate over USB - a local, on-device library that itself sends no data anywhere. The app includes no advertising SDKs, no analytics libraries, and no crash-reporting services.

EggSPEED is not currently distributed through the Google Play Store; it is downloaded directly as an APK file from this website.

8. Children's Privacy

EggSPEED is not directed at children under the age of 13 and we do not knowingly collect any personal information from children.

9. Changes to This Policy

If we update this Privacy Policy, we will post the revised version on this page with an updated "Last updated" date.
