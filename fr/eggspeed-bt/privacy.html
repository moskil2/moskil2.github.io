Module Bluetooth EggSPEED

Politique de confidentialité

Dernière mise à jour : 15 octobre 2026

Ceci est une traduction. Seule la version anglaise de cette politique de confidentialité fait foi.

Le module Bluetooth EggSPEED se contente de faire passer les données entre l'appli EggSPEED sur votre téléphone et le contrôleur de votre vélo, par une liaison Bluetooth locale. Il n'a pas de connexion Internet et ne collecte, n'enregistre ni ne transmet aucune donnée personnelle.

1. Ce qu'est le module

Le module Bluetooth EggSPEED est un convertisseur matériel à monter soi-même : un module série Bluetooth (DSD TECH BT-06 ou HC-06), un convertisseur abaisseur d'alimentation et deux résistances, que vous assemblez à partir du guide gratuit publié sur GitHub. Il se branche sur le connecteur HIGO 5 broches du contrôleur Bafang et remplace le câble de programmation USB OTG. Nous ne le vendons pas.

2. Circulation des données

Lorsqu'EggSPEED est connectée, le module transmet les données série du contrôleur (configuration et télémétrie en direct comme la vitesse, la puissance, le courant et la tension) à votre téléphone en Bluetooth Classic (SPP), et renvoie les commandes d'EggSPEED au contrôleur. C'est tout.

  • La liaison est locale et directe, entre votre téléphone et le module sur votre vélo
  • Rien n'est envoyé à nous, sur Internet ni à des tiers
  • Le module n'enregistre, ne met en mémoire tampon ni ne conserve aucune donnée de conduite

3. Données stockées dans le module

Le module Bluetooth ne conserve que ses propres réglages, définis lors de sa programmation : son nom Bluetooth, son code PIN et sa vitesse série (1200 bauds). Il ne contient aucune information personnelle, aucune position ni aucune donnée de conduite.

4. Appairage et code PIN

L'appairage utilise l'appairage Bluetooth standard avec un code PIN. Le module est livré avec le code PIN par défaut 1234. Nous recommandons vivement de définir votre propre code PIN lors de la programmation du module (manuel 1 du guide de montage), pour que personne à proximité ne puisse s'appairer avec votre vélo tant que la batterie est allumée. Éteignez la batterie avec son propre interrupteur après la sortie - cela éteint aussi le module.

5. L'appli EggSPEED

Le module s'utilise avec l'appli Android EggSPEED. Ce que l'appli fait des données sur votre téléphone est décrit dans la politique de confidentialité d'EggSPEED. En bref, EggSPEED garde tout sur votre appareil et ne demande aucun accès à Internet.

6. Ce site web

La page du module intègre une vidéo d'installation hébergée sur YouTube et charge ses polices depuis Google Fonts. Lorsque le lecteur vidéo se charge ou lit la vidéo, YouTube (Google) peut traiter des données selon sa propre politique de confidentialité. Les liens vers GitHub ouvrent le site de GitHub, qui a sa propre politique de confidentialité. Ce site lui-même n'utilise aucun outil d'analyse.

7. Protection des enfants

Le module et son guide de montage ne s'adressent pas aux enfants de moins de 13 ans, et nous ne collectons pas sciemment d'informations personnelles concernant des enfants.

8. Modifications de cette politique

Si nous mettons à jour cette politique de confidentialité, nous publierons la version révisée sur cette page avec une nouvelle date de « Dernière mise à jour ».
